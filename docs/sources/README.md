## Ιστορικές αντιφάσεις
Οι πρώτες ενότητες μπορεί να λένε ότι κανένας τύπος δεν έχει αποφασιστεί ή ότι δεν έχει επιλεγεί ανανέωση εξασθένησης. Μεταγενέστερες ενότητες καταγράφουν νέες διευκρινίσεις. Ιδίως §21 υπερισχύει του ανοιχτού ερωτήματος §20 και §23 του αντίστοιχου §22. Η αρχική απορριφθείσα τριάδα δεν απαγορεύει τον μεταγενέστερο Ενισχυτή του χρήστη. Οι μεταγενέστερες εντολές ανάπτυξης υπερισχύουν της παλιάς αναμονής «χωρίς κώδικα», χωρίς να εγκρίνουν αυτόματα όλες τις τιμές.
